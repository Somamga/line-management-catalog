# 回線管理・公開料金カタログ

個人用の回線管理アプリが取得する、署名付きの公開料金データです。通信事業者の公式配布物ではありません。

- `catalog-v1.json`：アプリ向けのEd25519署名付きJSON。署名対象の本文をbase64で格納しています。
- `catalog-source-v1.json`：上記本文の読みやすい表示用JSON。アプリはこのファイルを直接反映しません。
- 配布版：1／確認日：2026年10月26日／確認期限：2026年11月30日00:00（日本時間）。
- 初期収録：3事業者・3プラン。全事業者・全割引・個別契約条件の網羅を保証しません。

## 更新と検証

保守者は公式の料金表・変更告知を確認し、既存の安定IDを保持して配布版を増やします。同じ配布版の内容は差し替えません。署名鍵は公開せず、アプリは固定の公開鍵で署名・形式・値・期限・版を検証します。署名は配布元と本文の同一性の確認であり、料金の正しさや公式の承認を保証するものではありません。

アプリは更新候補の差分を表示し、利用者が確認した項目だけを反映します。保存済み契約の金額・特典・過去履歴を自動変更しません。取得や検証に失敗しても保存済み情報を保持します。期限後の新規反映には再確認した新しい配布版が必要です。

公開内容は料金・条件・出典・確認日などだけです。個別の契約、電話番号、書類、利用履歴、秘密鍵、APIキー、アプリのソースコードは含みません。有料APIや自動スクレイピングを利用した更新は行っていません。
